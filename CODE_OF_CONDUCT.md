# Community Code of Conduct

## Our standard

We want Breachwright to be a practical, respectful place for security practitioners, developers, and learners.

Examples of constructive participation include:

- Giving technical feedback with clear evidence
- Respecting different experience levels and backgrounds
- Keeping discussions focused on the project and authorized security work
- Accepting correction and helping others recover from mistakes
- Protecting customer data and vulnerability details

Unacceptable behavior includes harassment, discriminatory language, threats, deliberate disruption, publishing another person's private information, or using project spaces to encourage unauthorized access.

## Enforcement

Maintainers may edit or remove contributions, comments, issues, or other participation that violates this standard. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

Report conduct concerns privately to support@adventcybersecurity.com. Include links or screenshots when possible. Do not use this address to disclose security vulnerabilities; follow `SECURITY.md` for those reports.

Maintainers will handle reports as privately as practical and will avoid conflicts of interest when reviewing them.
