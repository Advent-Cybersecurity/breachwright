# Support

Breachwright is a community open-source project.

Use GitHub issues for reproducible bugs and feature proposals. Use GitHub discussions for setup questions, workflow ideas, and general community help when discussions are enabled.

Advent Cybersecurity created Breachwright and maintains the official repository, but the open-source release does not include a warranty, guaranteed response time, hosted AI access, or commercial support entitlement.

For vulnerability reports, follow `SECURITY.md`.
